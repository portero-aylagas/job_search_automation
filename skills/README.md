# Skills Directory

This directory documents the skills used or created for this project.

Each skill should be understood as one of the following:

- `runtime/project skill`
- `development/support skill`

This distinction makes it clear whether a skill affects the application's
runtime behavior or only supports the way the repository is developed.

## Current Skills

- `safe_project_improvement_system/`
  Development/support skill used during implementation to improve quality,
  review changes, and guide safe refactoring. It is not part of the runtime
  application unless explicitly integrated into the codebase.
